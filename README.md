# Helo! Creative — Interactive Scrollytelling Revamp Prototype

Landing page revamp interaktif untuk **Helo! Creative** (`helocreative.co.id`) dengan fitur *scrollytelling* cinematic: dari eksterior gedung, masuk ke creative studio, hingga landing di meja kerja dengan 3 hotspot layanan interaktif.

## Fitur Utama:
1. **Scrollytelling Engine (GSAP + ScrollTrigger):**
   - **Scene 1 (Scroll 0% - 30%):** Eksterior gedung Helo Creative + Headline utama *"Helping Brands Say 'Hi!', Loud and Clear"*.
   - **Scene 2 (Scroll 30% - 65%):** Transisi kamera meluncur masuk ke dalam creative studio / workshop.
   - **Scene 3 (Scroll 65% - 100%):** Viewport dipin di *Creative Desk Workstation* dengan 3 radar hotspot berdenyut.
2. **Interactive Service Hotspots di Meja Kerja:**
   - **Branding & Design:** Hotspot di sketchbook/pens (Logo, Brand Guidelines, Packaging, Typography).
   - **Digital Marketing:** Hotspot di laptop analytics screen (Social Media, Performance Ads, Analytics Dashboard).
   - **Photo & Videography:** Hotspot di kamera Sony Cinema & lens (Commercial Photoshoot, Video Branding, Reels/TikTok).
   - *Klik/hover pada hotspot membuka glassmorphic modal preview lengkap dengan scope of work dan tombol order direct WhatsApp.*
3. **Pillar Values Section:**
   - 3 Guiding Values Cards: *Creative is key*, *Partnership engagement*, dan *Result oriented*.
4. **WhatsApp Direct CTA & Floating Action Button:**
   - Hubungkan langsung ke WhatsApp tim Helo Creative (+62878-7752-1839) dengan pesan inquiry otomatis per layanan.
5. **Tone & Style:**
   - Brand Colors: Electric Blue (`#0095eb`), Warm Coral/Orange (`#d18f4f`), Dark Slate (`#161922`), Dark Surface (`#1c202c`), Crisp White.

## Cara Preview / Menjalankan:
Buka file `index.html` langsung di browser, atau jalankan server lokal:

```bash
cd /home/ubuntu/OpenMausBot/MrM/helo-creative-revamp
python3 -m http.server 8080
```
Buka browser di `http://localhost:8080`.
